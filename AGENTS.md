# Agents guide

## Check the license before adding anything

Before adding anything we did not make, free or paid (a package, icon, font, image, sound, model, vendored file, downloaded runtime), read its actual license for the exact version or set you are taking.

- **Fine:** permissive licenses such as MIT, BSD, Apache-2.0 and ISC.
- **Stop and ask Philip:** GPL or AGPL, non-commercial terms, "free for small teams" terms, source-available licenses, or no license at all.
- **Ship the notices with the product:** license notices go inside what we ship (a bundled file reachable from an about or licenses screen), not only on a website.
- **List what a package manager can't see** in `ASSETS.md`, with its version, license, license file and source. Create the file if this repo doesn't have one yet.
